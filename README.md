## Ticket Hub

A modern ticket booking web application built with React.js.  
Ticket Hub provides a simple and user-friendly interface for users to explore and book tickets through a clean web experience.

## Live Demo

[View Ticket Hub Live] (https://ticket-hub-lake-nu.vercel.app)


## About The Project

Ticket Hub is a React-based web application developed to provide a smooth and simple ticket booking experience.

The project focuses on creating a clean user interface, easy navigation, and a responsive web experience.

This project was created as a practical application of frontend development concepts and React.js.


## Features

- Ticket booking interface
- User login interface
- Simple and easy navigation
- Responsive user interface
- Fast React-based frontend
- Clean and modern UI
- Deployed and accessible online


## Technologies Used

- **React.js** – Frontend framework
- **JavaScript** – Application logic
- **HTML5** – Structure
- **CSS3** – Styling
- **Node.js & npm** – Project and package management
- **Git & GitHub** – Version control
- **Vercel** – Deployment
